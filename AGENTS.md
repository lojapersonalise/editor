# Entrega de vídeos

Preferência explícita do usuário: entregar os vídeos finais deste projeto pelo
GitHub, na pasta `videos/` do repositório `lojapersonalise/editor`.
Os links locais `/workspace/...` falharam na interface; o download pelo GitHub
foi testado pelo usuário e funcionou.

Ao entregar um vídeo solicitado:

1. Preserve os arquivos originais e as alterações existentes.
2. Salve o MP4 final em `videos/`, com nome claro. Preserve versões anteriores
   quando a nova entrega for uma revisão.
3. Valide o arquivo. Faça commit somente dos arquivos da entrega e envie para
   `main` sem force-push, preservando mudanças remotas. Se houver bloqueio de
   acesso ou proteção da branch, informe-o sem declarar que o envio ocorreu.
4. Confirme o envio antes de apresentar o link de download:
   `https://github.com/lojapersonalise/editor/raw/refs/heads/main/videos/NOME.mp4`
5. Inclua, se necessário, o link da página do arquivo:
   `https://github.com/lojapersonalise/editor/blob/main/videos/NOME.mp4`
   Oriente a usar **Download raw file** e entrar no GitHub se o repositório
   for privado.

Essa preferência autoriza a entrega dos vídeos finais solicitados neste
repositório; não autoriza publicar originais, credenciais ou materiais pessoais
não solicitados. Não use links locais como único meio de entrega.
